Projet phare — DevOps Lab

Laboratoire DevOps de bout en bout — projet personnel github.com/brojalloo/devops-lap
  • Pipeline CI/CD Jenkins à 9 étapes : checkout, installation, tests automatisés, analyse de qualité (SonarQube), Quality Gate, build Docker, scan de sécurité (Trivy), déploiement, health check.
  • Deux gates bloquants intégrés à la chaîne — Quality Gate SonarQube et scan Trivy sur les vulnérabilités CRITICAL — avec rapport archivé automatiquement.
  • Monitoring et observabilité complets : Prometheus, Grafana, Node Exporter et cAdvisor ; suivi des erreurs applicatives avec Sentry.
  • Gestion sécurisée des secrets via Jenkins Credentials — aucune clé ni DSN en clair dans le dépôt Git. Infrastructure as code préparée avec Terraform.
